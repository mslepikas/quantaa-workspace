GB10 HARDWARE INFO:
===================

GB10 (GeekPi 4) Specifications:
=======================

Current Specs (as of 2026):
- **CPU:** ARM Cortex-A72 / A53
- **Architecture:** ARMv8-A
- **Clock Speed:** 1.8-2.0 GHz
- **RAM:** 4-8 GB
- **Storage:** NVMe SSD
- **Display:** 4 monitors
- **Use Case:** OpenClaw server
- **Location:** Home lab

ARM CPUs IN GB10:
=================

Processor Options:
1. **Rockchip RK3399**
   - Dual Cortex-A72 + Quad A53
   - 2GHz max
   - Mali-T720 GPU
   - Common in GB10

2. **Allwinner A64**
   - Quad Cortex-A53
   - 1.5GHz
   - Mali-400 GPU
   - Entry-level GB10

3. **Amlogic S905X3**
   - Quad Cortex-A7
   - 2GHz
   - Mali-G31 GPU
   - Modern GB10

4. **Intel N100 (ARM variant)**
   - ARM-compatible
   - 65W TDP
   - 800MHz ARM cores
   - CloudReady
