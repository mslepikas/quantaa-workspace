## DNS Appliance Idea ("DNS in a Box")
- Mark's idea: low-cost appliance with Technitium DNS pre-installed for home networks
- Features: ad blocking, malware scanning, private DNS, AI log analysis
- Target: $129 hardware + optional $5/mo managed protection
- Hardware research:
  - Lenovo Tiny: good but needs external brick
  - Dell OptiPlex 3060/7060 Micro is the sweet spot — i5-8th gen or newer, internal PSU board, Tiny footprint
  - i5-8500T or i5-9500T (6-core) preferred for DNS + ClamAV + Ollama LLM workloads
  - Target price: $40-$60/unit in lots, $200-$250 for 2 fully-built prototypes
  - All micro desktops need external power adapter (no true brickless option except Pi)
  - Avoid sellers charging $130+/unit or $288/2-unit lots — market price is $40-$60/unit
  - "Ownership tag" on Dell corporate units can cause boot issues — avoid
  - Look for lots that include SSD and RAM
  - Technitium is AGPL — can run commercially, just can't sell "Technitium" as your brand name
- Competitive landscape:
  - Firewalla Purple SE ($79-$129) — closest competitor, but firewall-first not DNS-first
  - MakerBright AdGuard appliance ($74.99) — out of stock, small player
  - Vilros Raspberry Pi kits — DIY, not real product
  - No one is doing DNS-first + malware scanning + local AI insights
  - UniFi CyberSecure is $99/yr cloud-based — this appliance would be local, no cloud dependency
- Next step: buy Dell OptiPlex 3060/7060 Micro lots from eBay for $40-$60/unit with SSD included
- eBay market for OptiPlex lots is inflated right now — $149-235 for singles, $599-999 for lots with no SSD — all overpriced
- Apple Mini sold out globally, causing surge in micro desktop prices
- Nonaym is the chosen brand (nonaym.ai domain registered) — named after Jane Doe concept, anti-Elmo, privacy-focused
- Product line split into two tiers:
  - **Nonaym Lite** — $80-150 OEM target, N100/N150, 8-16GB RAM, 128-256GB SSD, dual LAN if possible. Runs Technitium + blocklists + dashboard + health checks + optional ClamAV. Normal consumers.
  - **Nonaym AI** — $250-500 target, 16-32GB RAM, 512GB SSD, Ryzen i5 or i7 preferred. Runs Technitium + ClamAV + Ollama + local small model + device behavior summaries. AI assistant layer.
- Hardware search pivoted to Beelink EQi12 (i5-1235U 10-core, 16GB, 500GB SSD ~$200-250 new) and MSI Cubi 5 as new-in-stock alternatives to Dell lots
- Raspberry Pi 5 rejected — "too much a toy" — need real x86 computer
