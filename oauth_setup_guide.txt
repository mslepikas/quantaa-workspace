=============================

CURRENT STATUS:
================

STEPS TO MIGRATE:
================

STEP 1: SET UP ENVIRONMENT FILE
===================
1. Create .env file (encrypted)
2. Store API keys in .env
3. Load from env in OpenClaw

STEP 2: ENABLE OAUTH (OPTIONAL)
===================
1. Set up OpenAI OAuth
2. Use OAuth tokens instead of keys
3. More secure than API keys

STEP 3: PASSWORD MANAGER INTEGRATION
===================
1. Export to password manager
2. Auto-fill in OpenClaw
3. Encrypted storage

SECURITY BEST PRACTICES:
========================
- .env file: chmod 600
- Password manager: Bitwarden, 1Password
- Never commit keys to Git
- Rotate keys quarterly
- Use OAuth when available

ENVIRONMENT FILE LOCATION:
=====================
~/.openclaw/.env

SAMPLE .env FILE:
=================

# OpenAI API Configuration
OPENAI_API_KEY=sk-proj-xxxxx
OPENAI_BASE_URL=https://api.openai.com/v1

# OAuth (if available)
OPENAI_CLIENT_ID=xxxxx
OPENAI_CLIENT_SECRET=xxxxx

# Alternative providers
OLLAMA_API_KEY=ollama-local
OLLAMA_BASE_URL=http://127.0.0.1:11434

OPENAI OAUTH FLOW:
==================

1. Register OAuth app

ENVIRONMENT VARIABLE USAGE:
====================

In OpenClaw config:

{
  "models": {
    "providers": {
      "openai": {
        "apiKey": "${OPENAI_API_KEY}",
        "baseUrl": "${OPENAI_BASE_URL}"
      }
    }
  }
}

Or in shell:
export OPENAI_API_KEY="..."

OAUTH TOKEN REFRESH:
===================

OAuth tokens expire!
- Set refresh mechanism
- Auto-refresh before expiry
- Handle token rotation

SAMPLE SCRIPT:
==============

#!/bin/bash
# refresh_openai_tokens.sh

source ~/.openclaw/.env
export OPENAI_TOKEN=$(get_oauth_token)
echo "Token refreshed successfully"
